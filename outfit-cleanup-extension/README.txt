OUTFIT CLEANUP FOR ROBLOX — v1.0.0 (unofficial)

Install locally:
1. Extract the ZIP to a folder and keep the extracted files together.
2. Open opera://extensions (Opera GX) or chrome://extensions (Chrome).
3. Enable Developer mode, choose Load unpacked, and select the folder containing manifest.json.
4. Refresh https://www.roblox.com/my/avatar and open Avatars > Creations.
5. Look for Manage Outfits near Create New Character, or at the bottom right if the page layout differs.

Use:
Nothing is selected by default. Check outfits you want to DELETE. Unchecked outfits are kept.
Review the list, type the requested confirmation, and verify the backup download before accepting the final confirmation. Test with one unwanted outfit first. Delete operations are permanent. The JSON backup records outfit details; it is not an automatic restore utility. Stop prevents further requests after the current one. Refresh the avatar editor afterwards.

Privacy and scope:
No account cookie reading, no external analytics, no password prompts, no additional extension API permissions. Runs only on the Roblox avatar editor, in its page context, to use the signed-in Roblox session. Requests go to Roblox user, avatar and thumbnail APIs; images are hosted on Roblox CDN. Outfit backups are downloaded locally. Do not share backup files publicly. Not affiliated with Roblox.

Testing:
The manager is based on the previously working script, but the extension wrapper and live-site compatibility have not been tested in a real browser/account. JavaScript syntax and manifest/package structure were checked. Other extensions or changes to the avatar editor may affect button placement. For public release, test on Chrome and Opera GX and review browser store rules, privacy disclosures and Roblox terms before publishing.
